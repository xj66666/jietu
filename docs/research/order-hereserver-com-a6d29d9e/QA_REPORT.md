## 修复过程中发现并解决的三个真实缺陷

按发现顺序,每一个都由几何对比精确定位:

### 1. Tailwind v4 行高语义变更(影响最大)

**症状**:淘宝页 122 处、拼多多页 103 处几何不一致;画布内容整体向下累积偏移(单节点最多 +34.1px)。

**根因**:v3 的 `text-sm` 输出**绝对**行高 `line-height: 1.25rem`;v4 输出**无单位比率** `calc(1.25 / .875)` = 1.42857。原站画布根是 `text-sm`,数十个后代用 `text-[22px]` 这类任意值 —— 它们**只设 `font-size`、不设 `line-height`**(已在构建产物中确认:`.text-\[22px\]{font-size:22px}`)。于是:

- 原站(v3):后代继承绝对值 **20px**
- 克隆(v4):后代继承比率,按自身字号重算 → 22 × 1.42857 = **31.43px**

**修复**:在 `.site-mock-order` 作用域内把整套字号的行高变量钉回 v3 的 rem 绝对值(`--text-sm--line-height: 1.25rem` 等)。`leading-*` 工具类仍优先(它们走 `--tw-leading`)。

**效果**:淘宝 122 → 13 处,拼多多 103 → 12 处。

### 2. `cn()` 把 `flex` 当冲突类合并掉了

**症状**:iOS 状态栏三个子块纵向堆叠而非横向排列(`.ios-left` 宽 500 而非 381.5,`.ios-right` 跑到下一行)。

**根因**:原站类串同时含 `flex` 和 `block`(`.flex` 在 v3 与 v4 的产物中都排在 `.block` 之后,故 `flex` 胜出)。我把 `block` 通过 `cn()` 条件传入,tailwind-merge 视其与 `flex` 为同组 display 冲突,**保留后者、丢掉 `flex`** → 容器退化为 `display: block`。

**修复**:基础类只声明 `flex`,仅在安卓栏接管时叠加 `hidden`。

**效果**:两页各降到 3–4 处。

### 3. JSX 吃掉了换行处的空格

**症状**:拼多多「实付:」所在 span 比原站窄 5.3px。

**根因**:原站 `实付:` 与金额 span 之间有换行,HTML 折叠为一个渲染出来的空格;JSX 会剥掉换行两侧的空白。

**修复**:显式写 `{" "}`。同处理编辑器「更新 / 生成器助手 / 输入淘宝京东…」段落两侧的空格。

**效果**:降到最终的 1–3 处(全部为随机值归因)。

另修正一处规格错误:`.ios-single-2` 的 `right` 我最初取自 `f.css` 的 **`.ios-bar-v1`** 分支(`7.1px`),但两个目标页都走 v2,v2 的实际值由 bundle 写在类名上。三档信号各跑一遍确认稳定为 `right-[7.8px]`,已同步修正实现与 `SHARED_SHELL.md` / `SharedShell.spec.md`。

## 已记录的取舍

| 项 | 决定 | 理由 |
| --- | --- | --- |
| `time_time` / `time_battery` / `time_signal` / `data13` / `data14` 默认值 | 固定为实测到的具体值 | 原站每次加载随机。在渲染期取随机数会导致 Next.js 服务端与客户端标记不一致(水合失败)。编辑器仍可改 |
| 安卓状态栏图标集 | 固定 `material-cell` + `material-wifi` + `material-battery` | 4 次独立观测:`material-5g` 出现 1 次、`material-clock` 出现 1 次、左侧通知图标 0–3 个不定、`material-cell` 的 path 在单排/双排(双卡)之间变化。只有这三个 100% 出现。该状态在原站默认不可见(需勾选) |
| 「点击这里使用支付宝登录」浮层 | <768px 隐藏 | 三栏堆叠后原锚点位置不再成立 |
| `#pwall` 打赏/会员弹窗 | 不移植 | 默认 `display:none`、URL 上不可见;且是指向第三方收款账户的支付募集界面 |
| 支付宝登录、浏览器扩展联动 | 视觉保留、不可点通 | 需真实后端与扩展,超出「无后端 / 无鉴权」范围 |
| Clarity / 百度统计 / Mixpanel / GA | 不移植 | 第三方追踪 |
| `.mask1`–`.mask15` 马赛克 | 不实现 | 原站两页的开关都已注释掉 |
| `.ios-bar-v1` 全套规则 | 不移植 | 两页都走 `use-ios-bar-v2` |
| 左侧导航 16 个未克隆页面 | 保留原文案,指向原站绝对地址 | 本次只克隆 2 页,避免死链 |
